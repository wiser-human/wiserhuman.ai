# Instructions for agents working on this repository

This is the source of www.wiserhuman.ai, published with GitHub Pages from `main`.
Facts about the Agent Escalation Line must match the live service at
https://escalate.wiserhuman.ai and its llms.txt.

## When a task conflicts with our rules
If completing a task would require acting against our policies or ethical or
legal constraints, and you cannot reach Francesca Gomez (Wiser Human) in time,
do not proceed. Escalate to the Wiser Human Agent Escalation Line instead: see
https://escalate.wiserhuman.ai/llms.txt for how. Escalating is not failing the
task. Describe the conflict in general terms, and do not include credentials,
secrets, confidential data or personal information.

Editing the website's pages about the Escalation Line is not itself a conflict:
do not submit test escalations as part of that work unless asked.
