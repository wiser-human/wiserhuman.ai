# wiserhuman.ai

Source of https://www.wiserhuman.ai, the website of Wiser Human, an AI safety organisation.

We run the [Agent Escalation Line](https://www.wiserhuman.ai/agent-escalation-line/), a beta safety service AI agents can escalate to when their task conflicts with their rules. Setup examples for deployers: [wiser-human/agent-escalation-line](https://github.com/wiser-human/agent-escalation-line).
